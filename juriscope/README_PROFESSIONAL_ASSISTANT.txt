تعديل المساعد القانوني الاحترافي - Mizan

الملفات المعدلة:
- app/services/ai_service.py
- app/routes/api.py
- app/templates/assistant.html
- app/static/js/assistant.js

ما تمت إضافته:
1. تحويل المساعد من سؤال/جواب عام إلى Legal Workbench احترافي.
2. إضافة أوضاع المساعد:
   - تحليل قضية أو موقف قانوني
   - بحث قانوني في التشريعات والمواد
   - تحليل مستندات وملف قضية
   - مراجعة عقد أو اتفاقية
   - صياغة مذكرة / إنذار / لائحة
   - استراتيجية دعوى أو دفاع
   - استشارة شركة / امتثال
3. إضافة بنية جواب احترافية تشمل:
   - الخلاصة القانونية المهنية
   - الوقائع والافتراضات
   - المسائل القانونية
   - النصوص والقواعد القانونية الحاكمة
   - التحليل المبني على المصادر
   - تطبيق القانون على الوقائع
   - نقاط القوة والضعف
   - ما قد يدفع به الخصم
   - التوصيات والاستراتيجية
   - المستندات والمعلومات الناقصة
   - درجة الثقة وحدود المصادر
4. تمرير assistant_mode من الواجهة إلى API ثم إلى Gemini.
5. إبقاء الاعتماد على مصادر Mizan المعتمدة فقط عند ذكر مواد قانونية.
6. عدم إلغاء نظام القضايا أو رفع المستندات الحالي.

بعد الاستبدال:
python -c "from app.production_schema import ensure_production_schema; ensure_production_schema(); print('DONE')"
python main.py
